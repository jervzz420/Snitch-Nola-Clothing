Snitch Nola Clothing — PyScript Business Website

Snitch Nola Clothing is a colorful clothing website made for our EVD and Business Analytics final project. It is designed for students and young adults who want comfortable, trendy, and affordable clothes.

Brand Tagline: Affordable Style for Every Student.

Project Files:

Here are the main files and their purposes:

index.html — The home page with our promotional video.

shop.html — Shows our products and includes an order form with a price summary.

story.html — Tells the story behind our clothing brand.

contact.html — Contains our contact information and social media links.

style.css — Controls the website's colors, layout, and design.

main.py — Handles product search, filters, quantity buttons, price calculations, and order form checking.

images/ — Contains our brand logo and product pictures.

videos/snitch-nola-promo.mp4 — Our 50-second promotional video shown on the home page.

How to Run the Website

To run the website on your computer, follow these steps:

Make sure Python 3 is installed on your computer.

Open Command Prompt or the terminal in VS Code.

Go to your project folder.

Run this command:

python -m http.server 8000

Open your browser and visit http://localhost:8000.

Click index.html to open the website.

Note: It is better to run the website through a local server instead of opening the HTML file directly because PyScript works better this way.
